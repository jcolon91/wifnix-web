Wifnix AI Studio

Handoff · 8 de octubre de 2026 · Créditos prepagados con Stripe + generación con la API de Higgsfield

Qué es

El cliente entra a portal.wifnix.com/ai-studio.html con su cuenta de Wifnix, recarga créditos ($10/$25/$50/$100) con Stripe Checkout, ve el precio exacto de cada imagen o video antes de generarlo, y el saldo se descuenta solo si lo aprueba. Si la generación falla, se le devuelve. El Estratega (Claude) le arma análisis, ángulos, guion y prompts. Higgsfield es el motor interno y el cliente no lo ve.

Cómo se garantiza la ganancia

  • Antes de cada generación se pide el costo real a Higgsfield (/estimate). Sin costo, no se genera.
  • Precio = costo × AI_MULTIPLICADOR (2× por defecto, nunca menos de 1.10×), redondeado hacia arriba, mínimo 25¢. Todo en centavos enteros.
  • La base de datos rechaza cualquier generación con precio menor que el costo.
  • Si un envío queda ambiguo (Higgsfield pudo haber cobrado), no se reembolsa solo: pasa a revisión y te llega un correo.

Instalación en el VPS

  1. Higgsfield: crea la llave en console.higgsfield.ai y recarga saldo de API (es aparte de tu plan).
  2. Stripe: Developers → Webhooks → Add endpoint https://api.wifnix.com/api/ai/stripe/webhook con los eventos checkout.session.completed, checkout.session.async_payment_succeeded, charge.refunded, charge.dispute.created. Copia el whsec_.
  3. Sube los archivos al repo y bájalos al servidor como siempre.
cd /var/www/wifnix/backend
psql -U postgres -d wifnix -f migracion-ai-studio.sql
mkdir -p /var/www/wifnix/ai-media
# .env: HF_CREDENTIALS, STRIPE_AI_WEBHOOK_SECRET, AI_WEBHOOK_TOKEN, AI_FIRMA_SECRET (ver .env.example)
openssl rand -hex 24   # AI_WEBHOOK_TOKEN
openssl rand -hex 32   # AI_FIRMA_SECRET
python3 ai_studio_instalar.py
node --check server.js && pm2 restart wifnix-api

ai-studio.html va donde se sirve el portal, al lado de portal.html.

Probar antes de abrirlo

  1. Usa llaves de Stripe en modo test y paga con 4242 4242 4242 4242.
  2. Genera una imagen barata (Imagen realista, 2K, 1) y confirma que el saldo baja y el archivo aparece.
  3. Revisa GET /api/admin/ai/resumen: ingreso, costo y ganancia.

Admin

  • GET /api/admin/ai/resumen?dias=30 — recargas, ingreso, costo de Higgsfield, ganancia, saldo pendiente de clientes
  • GET /api/admin/ai/revision — generaciones que necesitan que las mires
  • PUT /api/admin/ai/generaciones/:id/resolver con {"accion":"reembolsar"}, {"accion":"vincular","hf_request_id":"..."} o {"accion":"cerrar"}
  • PUT /api/admin/ai/billeteras/:uid/descongelar — después de una disputa o reembolso

Verificado

42 pruebas contra PostgreSQL real con Stripe y Higgsfield simulados: recargas que no se duplican, 8 clics simultáneos con saldo para uno (solo 1 pasa), reembolsos únicos, webhooks falsos ignorados, envíos ambiguos a revisión, candado del reconciliador, 10,000 precios al azar nunca bajo costo. Firma real de Stripe validada con el SDK. server.js parcheado arranca y responde. Página renderizada en tamaño de iPhone, tema claro y oscuro, sin errores de JavaScript.

Pendientes y avisos

  • Términos de Higgsfield prohíben revender el acceso a la API (§5.2(i), §11.5); permiten apps para clientes con valor propio (§1.2). Pídeles confirmación por escrito antes de cobrar.
  • El repo jcolon91/wifnix-web está público. Ponlo privado.
  • Bug existente: el webhook de órdenes /api/pagos/stripe/webhook está registrado después de express.json(), así que la firma de Stripe nunca valida y las órdenes pagadas con Stripe no se marcan como pagadas.
  • package-lock.json no coincide con package.json (node-fetch 2 vs 3): npm ci falla.
  • IVU: consulta con tu contable si aplica a los créditos.
  • La página está solo en español; el resto del sitio es bilingüe.
  • Modelos: solo los 6 verificados en el OpenAPI público. Para añadir Veo, Seedance u otros, busca su ruta en console.higgsfield.ai y haz INSERT en ai_modelos.
