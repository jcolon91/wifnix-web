Qué es

El cliente entra a portal.wifnix.com/ai-studio.html con su cuenta de Wifnix y recarga créditos ($10/$25/$50/$100) con Stripe; el dinero cae en la cuenta de Wifnix. Antes de cada imagen o video ve el precio exacto, y solo se descuenta si lo aprueba. Si falla, se le devuelve. Los modelos se usan directo con cada proveedor, y Higgsfield solo para Genjutsu y Kling. El Estratega (Claude) arma análisis, ángulos, guion y prompts por un precio fijo.

Las tarifas viven en ai_modelos.tarifa. Si un proveedor cambia su precio, actualiza la migración y vuelve a correrla: refresca tarifas sin tocar lo que activaste o desactivaste.

Cómo se protege la ganancia

  • Sin costo conocido no se genera. Una combinación que no esté en la tarifa se rechaza.
  • La base de datos no deja guardar una venta bajo costo ni un modelo de Google/MiniMax sin tarifa.
  • Google y MiniMax no aceptan reintentos seguros: un envío dudoso (corte de red, reinicio del servidor, respuesta sin imagen) va a revisión con correo, nunca a reembolso automático ni a reenvío.
  • Higgsfield sí: sus envíos cortados se reintentan con el mismo Idempotency-Key.
  • Los archivos se copian al VPS al terminar (Google borra a los 2 días, MiniMax en minutos). Si no se pueden copiar en 8 intentos, la generación va a revisión.

Instalación en el VPS

  1. Google: aistudio.google.com → Get API key, con facturación activa.
  2. MiniMax: platform.minimax.io → API Keys, y recarga saldo.
  3. Higgsfield: console.higgsfield.ai → API keys, y recarga saldo de API.
  4. Stripe: Developers → Webhooks → https://api.wifnix.com/api/ai/stripe/webhook con checkout.session.completed, checkout.session.async_payment_succeeded, charge.refunded, charge.dispute.created.
cd /var/www/wifnix/backend
psql -U postgres -d wifnix -f migracion-ai-studio.sql
mkdir -p /var/www/wifnix/ai-media
# .env: GOOGLE_AI_API_KEY, MINIMAX_API_KEY, HF_CREDENTIALS, STRIPE_AI_WEBHOOK_SECRET,
#       AI_WEBHOOK_TOKEN (openssl rand -hex 24), AI_FIRMA_SECRET (openssl rand -hex 32)
python3 ai_studio_instalar.py
node --check server.js && pm2 restart wifnix-api

Si nginx limita el tamaño de subida, súbelo a 110 MB para los videos de Genjutsu: client_max_body_size 110m; en el bloque de api.wifnix.com.

Un proveedor sin llave simplemente no aparece para el cliente: puedes arrancar con uno solo.

Admin

  • GET /api/admin/ai/resumen?dias=30: ingreso, costo por proveedor, ganancia y saldo pendiente de clientes
  • GET /api/admin/ai/revision: generaciones que necesitan que las mires
  • PUT /api/admin/ai/generaciones/:id/resolver con {"accion":"reembolsar"}, {"accion":"vincular","proveedor_id":"..."} o {"accion":"cerrar"}
  • PUT /api/admin/ai/billeteras/:uid/descongelar

Pendientes y avisos

  • Veo 3.1 son modelos "preview": Google puede retirarlos desde el 22-oct-2026. Su reemplazo, Gemini Omni Flash, todavía no publica precio para 1080p ni cómo se fija la duración; cuando lo haga, se añade como modelo nuevo. Si Veo deja de funcionar, desactívalo: UPDATE ai_modelos SET activo=false WHERE clave LIKE 'veo%';
  • No probado en vivo (no hay llaves en este ambiente): la primera generación real con cada proveedor debe hacerse con Stripe en modo test y tu propia cuenta.
  • Los precios de Veo vienen de una fuente secundaria que cita a Google (sept. 2026). Confírmalos en la consola de Google antes de abrir.
  • No sé si MiniMax cobra los videos que fallan; si los cobra, cada fallo te cuesta lo que costaba el video (el cliente igual recibe su crédito).
  • Google empieza con un límite de $10 cada 10 minutos; sube cuando hayas pagado $100.
  • Seedance (BytePlus) no está disponible en EE. UU./PR. Kling directo solo vende paquetes prepagados, por eso va por Higgsfield.
  • Términos de Higgsfield: prohíben revender la API cruda (§5.2(i), §11.5). Ahora solo se usa para Genjutsu y Kling dentro de tu producto; igual pídeles confirmación por escrito.
  • El repo jcolon91/wifnix-web está público. Ponlo privado.
  • Bug existente: el webhook de órdenes /api/pagos/stripe/webhook está después de express.json() y nunca valida la firma.
  • IVU: consulta con tu contable si aplica a los créditos.
